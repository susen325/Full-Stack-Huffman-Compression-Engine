================================================================================ About the Huffman Compression Engine The Vision ================================================================================ The Full-Stack Huffman Compression Engine was built to bridge the gap between low-level algorithmic efficiency and modern web accessibility. While most compression algorithms run quietly in the background of operating systems, this project brings the raw, mathematical power of a native C++ engine directly to the web browser. Under the Hood At the core of this platform is a custom-built C++ engine utilizing Huffman Coding, a fundamental algorithm for lossless data compression. The Algorithm: The engine reads an uploaded file, calculates the frequency of every single character, and constructs a minimum-priority binary tree. Characters that appear frequently are assigned ultra-short binary codes, while rare characters receive longer codes, effectively shrinking the overall file size. The Architecture: The platform features a containerized Node.js backend. When a file is uploaded, the server securely hands it off to the compiled C++ binary executing in a Linux cloud environment. The engine processes the data, generates a .huff archive, and logs the activity in a SQLite database. Security First File integrity and user privacy are prioritized at every step. The platform features strict session management, bcrypt password hashing for user accounts, and integrated Nodemailer OTP (One-Time Password) verification to ensure your file history and encryption passwords remain strictly in your control. About the Developer Developed by Susen Kumar, this project is the culmination of a deep passion for data structures, algorithmic optimization, and full-stack architecture. It represents the exciting challenge of taking theoretical computer science concepts—like tree traversals, priority queues, and bitwise operations—and deploying them as a scalable, cloud-hosted product.
